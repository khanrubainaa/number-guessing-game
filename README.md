
# Number Guessing Game

This is a simple Python CLI game where the computer
picks a random number between 1 and 100.

## Features
- Random number generation
- User guesses until the correct number is found
- Displays Too High or Too Low hints
- Counts the number of attempts
- Handles invalid inputs using try/except

## Concepts Used
- Random module
- While loop
- Functions
- If/elif/else
- Input
- Try/except
- F-strings

## How to Run

Open the terminal and type:

python number_guessing_game.py
